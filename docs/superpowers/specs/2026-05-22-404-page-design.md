# Design Spec: 404 Error Page (Nature Perdue)

## 1. Overview
Creation of a custom 404 (Not Found) page for "The Green Event" festival. The page follows the "Nature meets Electro" aesthetic with an immersive, atmospheric design titled "Nature Perdue" (Lost in the Forest).

## 2. Visual Design
- **Background:** Deep Forest (`#0a3f25`).
- **Typography:** 
    - "404": Montserrat, extra-bold, large scale.
    - Title: Montserrat, "Perdu dans la forêt ?".
    - Body: Nunito, inviting text.
- **Color Palette:** Cream/Sand (`#FEF7E0`) for text and Vibrant Green (`#00A651`) for primary actions.
- **Atmosphere:** 
    - Animated mist overlay using Framer Motion.
    - Falling leaves (`Leaf` component) and floating cubes (`Cube` component) with parallax effects.

## 3. Components & Features
- **FloatingElements:** Reused to create the "falling" effect.
- **Search Bar:** Functional search input to help users find artists or sections directly.
- **Call to Actions (CTAs):**
    - "Retour à l'accueil" (Primary, Vibrant Green).
    - "Découvrir la programmation" (Secondary, Outlined Cream).
- **Responsive:** Mobile-friendly layout with adjusted animation density for performance.

## 4. Technical Implementation
- **File:** `app/not-found.tsx` (Next.js special file for 404).
- **Animations:** 
    - `mist`: Infinite horizontal/diagonal drift.
    - `leaves`: Vertical translation with slight rotation.
- **Layout:** Flexbox/Grid centered container, full-screen height (`min-h-[calc(100vh-navbar-footer)]`).

## 5. Success Criteria
- User understands they are on an error page but remains immersed in the festival vibe.
- Clear path back to functional areas of the site.
- No performance degradation due to animations.
